# E-Commerce Database Management System

## Project Overview

This project demonstrates the design and management of an e-commerce database using MySQL.

## Technologies Used

* MySQL
* SQL

## Database Tables

* Customers
* Categories
* Products
* Orders
* Order Items
* Payments
* Employees

## SQL Concepts Practiced

* Database and table creation
* INSERT, SELECT, UPDATE, and DELETE
* WHERE, AND, OR, and LIKE
* ORDER BY and LIMIT
* Primary keys and foreign keys
* INNER JOIN, LEFT JOIN, and RIGHT JOIN

## Learning Outcome

This project helped me practise SQL queries, relational database design, table relationships, and foreign key constraints.
